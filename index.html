Jomok Subtitle Tool

Jomok Subtitle Tool is a private, internal script used by Dr. Jeongmok Cho to manage his own YouTube channel, Jomok-Jomok TV. It is not distributed, sold, or offered to any other user.

What it does

The channel publishes Korean-language medical education videos. The tool uploads translated subtitle tracks (English, Thai, Russian, Japanese) and localized titles and descriptions to the owner's own videos through YouTube API Services, so that viewers outside Korea can understand them.

How it uses YouTube API Services

  • captions.insert / captions.update / captions.list — upload and replace subtitle tracks on the owner's videos
  • videos.list / videos.update — read video metadata and set localized titles and descriptions
  • playlistItems.list — list the owner's own uploads

The tool runs on the owner's computer, signs in only with the owner's own Google account (OAuth 2.0), and does not access any other user's data.
